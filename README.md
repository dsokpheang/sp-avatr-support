# SP Avatr — support site

The two public pages App Store Connect requires for the **SP Avatr** iOS app:

- `index.html` — Support URL
- `privacy.html` — Privacy Policy URL

Served by GitHub Pages from the `main` branch. Plain static HTML, no build step:
edit a file, commit, push, and the change is live in a minute or so.
